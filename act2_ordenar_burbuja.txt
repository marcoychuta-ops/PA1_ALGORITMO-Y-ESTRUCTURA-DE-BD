ALGORITMO OrdenarBurbuja(lista, n)
1. intercambiado <- VERDADERO
2. pasada <- 1
3. MIENTRAS intercambiado Y pasada < n HACER
4.    intercambiado <- FALSO
5.    PARA i DESDE 0 HASTA n - pasada - 1 HACER
6.       SI lista[i] > lista[i + 1] ENTONCES
7.          INTERCAMBIAR lista[i], lista[i + 1]
8.          intercambiado <- VERDADERO
9.       FIN SI
10.    FIN PARA
11.    pasada <- pasada + 1
12. FIN MIENTRAS
13. REPORTAR lista
FIN ALGORITMO

' Vector del caso: [28, 15, 34, 21, 19, 40, 12, 26]
' Resultado (menor a mayor): [12, 15, 19, 21, 26, 28, 34, 40]
'
' COSTO:
'  - Mejor caso (ya ordenado): 1 pasada sin intercambios ⇒ 7 comparaciones ⇒ O(n)
'  - Peor caso (orden inverso): todas las pasadas comparan todos los pares
'    ⇒ n·(n-1)/2 = 8·7/2 = 28 comparaciones ⇒ O(n²)
'  La bandera "intercambiado" permite detectar el mejor caso sin recorrer de más.
